# 🎂 Дни рождения: календарь с напоминаниями

Простое веб-приложение для личного пользования: календарь, в котором можно хранить дни рождения друзей и близких. Работает в браузере телефона или компьютера, не требует регистрации и установки из магазина приложений. Все данные хранятся только у вас на устройстве.

> **Ссылка на приложение:** `https://russniger.github.io/birthdays/`

---

## Что умеет приложение

- **Календарь по месяцам** на русском языке, неделя начинается с понедельника. Сегодняшний день отмечен рамкой.
- **Заметки на любой день.** Нажмите на дату и добавьте человека: имя или любую заметку.
- **Несколько человек на одну дату.** В один день можно добавить любое количество именинников, каждый хранится отдельно.
- **Подсветка дней с заметками.** Дни, в которых есть записи, окрашены другим цветом.
- **Повтор каждый год.** Галочка «Повторять каждый год» включена по умолчанию: запись будет появляться на этой дате ежегодно.
- **Возраст именинника.** Если указать год рождения, приложение покажет, сколько человеку исполнилось или исполнится («Исполнится 36 лет»).
- **Фото-аватарки.** К каждому человеку можно добавить фото, которое показывается в кружке. Перед сохранением фото можно подогнать: перетащить пальцем и изменить масштаб.
- **Блок ближайших дат.** Вверху страницы показаны дни рождения на ближайшие 60 дней. Если сегодня чей-то праздник, это видно сразу.
- **Светлая и тёмная тема.** Переключается кнопкой 🌓, выбор запоминается.
- **Резервная копия.** Экспорт и импорт всех заметок текстом.
- **Напоминания через календарь телефона.** Можно добавить событие в любой календарь (файл `.ics`) или в Google Календарь. Событие повторяется каждый год, напоминание приходит в 9:00.
- **Ярлык на главном экране** с собственной иконкой. Открывается как обычное приложение.

## Конфиденциальность

- Приложение **не отправляет данные на сервер** и не содержит счётчиков или рекламы.
- Заметки, годы рождения и фотографии хранятся **только в памяти браузера** (localStorage) на вашем устройстве.
- Никто, включая автора, не видит ваши записи. У каждого пользователя, открывшего ссылку, свои собственные данные.

## Важные особенности и ограничения

| Что | Как работает |
|---|---|
| Уведомления | Страница **не может сама присылать уведомления**, когда она закрыта. Для напоминаний используйте календарь телефона (кнопки 📱 и 🔔). |
| Синхронизация | Между устройствами и браузерами **нет**. Заметки на телефоне и на компьютере независимы. Для переноса используйте экспорт и импорт. |
| Очистка данных | Если очистить данные браузера или удалить сайт из памяти, **заметки пропадут**. Периодически делайте экспорт. |
| Календарь телефона | Веб-страница не может записывать события в календарь напрямую. Событие нужно подтвердить в календаре одним нажатием после открытия файла. |
| 29 февраля | Запись на эту дату с повтором ежегодно отображается корректно только в високосные годы. Для таких дней рождения лучше дополнительно добавить запись на 28 февраля или 1 марта. |
| Разные браузеры | В каждом браузере (и в «установленном» ярлыке, и в обычной вкладке) может быть свой набор данных. Выберите один способ открытия и пользуйтесь им. |

## Как пользоваться

### Добавить день рождения
1. Откройте приложение и нажмите на нужную дату в календаре.
2. Введите имя или заметку (например, «День рождения Ивана»).
3. По желанию укажите год рождения и добавьте фото (кнопка «📷 Фото»).
4. Оставьте галочку «Повторять каждый год» и нажмите «Добавить».

### Изменить или удалить
Рядом с каждым человеком есть кнопки: ✏️ (изменить), 🗑 (удалить), 📱 (в календарь телефона) и 🔔 (Google Календарь).

### Поставить напоминание
- **📱:** передаёт файл `.ics` календарю телефона. Откройте файл и подтвердите добавление. Подходит для любого календаря (Samsung, Huawei, Apple, Outlook, Яндекс и других).
- **🔔:** открывает Google Календарь с заполненным событием, останется нажать «Сохранить».
- **«📅 Этот день в календарь (.ics)»:** добавляет сразу всех людей выбранного дня.
- **«📅 Все заметки в календарь (.ics)»** (в блоке «Резервная копия»): переносит все записи одним файлом. Используйте один раз, иначе в календаре возможны дубли.

События повторяются каждый год сами, поэтому добавлять их нужно один раз на человека. Если вы потом измените или удалите запись в приложении, в календаре ничего не изменится, поправьте там отдельно.

### Резервная копия
1. Нажмите «Экспорт»: весь список копируется текстом. Сохраните его в «Заметки» или отправьте себе.
2. Чтобы восстановить данные, вставьте этот текст в поле и нажмите «Импорт». Записи добавятся к существующим, повторы пропускаются.

Фотографии тоже входят в копию, поэтому текст может быть длинным. Вставляйте его целиком.

## Как опубликовать у себя (GitHub Pages)

Приложение состоит из статических файлов, поэтому его можно бесплатно разместить на GitHub Pages.

**Файлы проекта**

| Файл | Назначение |
|---|---|
| `index.html` | Само приложение (весь код в одном файле) |
| `manifest.json` | Название и настройки ярлыка на главном экране |
| `icon-192.png`, `icon-512.png` | Иконка приложения |
| `README.md` | Это описание |

**Шаги**
1. Зарегистрируйтесь на [github.com](https://github.com) и создайте **публичный** репозиторий с галочкой «Add a README file».
2. Нажмите «Add file» → «Upload files» и загрузите `index.html`, `manifest.json`, `icon-192.png` и `icon-512.png`. Названия файлов менять нельзя. Нажмите «Commit changes».
3. Откройте «Settings» → «Pages». В поле «Source» оставьте «Deploy from a branch», в поле «Branch» выберите `main` и `/ (root)`, затем «Save».
4. Через 1–3 минуты на этой же странице появится адрес вида `https://логин.github.io/название/`. Откройте его на телефоне.

Названия кнопок на GitHub могут немного меняться, потому что сайт обновляется.

## Как установить ярлык на телефон (Android, Chrome)

1. Откройте адрес приложения в Chrome.
2. Нажмите меню (три точки) и выберите «Установить приложение» или «Добавить на главный экран».
3. На главном экране появится ярлык с иконкой торта.

Если иконка не поменялась после обновления файлов, удалите старый ярлык и добавьте его заново.

## Технические сведения

- Один HTML-файл с вложенными стилями и скриптом, без внешних библиотек и без сборки.
- Данные хранятся в `localStorage` браузера (ключи `bd-notes` и `bd-theme`).
- Файл календаря формируется в формате iCalendar (`.ics`): событие на весь день, повтор `FREQ=YEARLY`, напоминание в 9:00.
- Фото уменьшается до 160×160 пикселей и сохраняется в формате JPEG, чтобы занимать мало места.
- Подходит для современных версий Chrome и других браузеров на Android, а также для компьютерных браузеров.
